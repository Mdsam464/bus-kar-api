# Git Auto-Sync Workflow

Whenever you complete a code modification, bug fix, or feature addition in this repository:
1. Automatically run `git add .`
2. Automatically run `git commit -m "<concise descriptive summary of changes>"`
3. Automatically run `git push origin main` outside the sandbox so the user's GitHub repository (`https://github.com/Mdsam464/bus-kar-api`) is continuously and automatically up to date without the user having to type git commands manually.
